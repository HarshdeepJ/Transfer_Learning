# Transfer Learning with Correspondences for Cross-Domain Transfer - README

## Overview
This project applies transfer learning with correspondences to convert code into pseudocode. The implementation is in Python using Jupyter Notebook (`.ipynb` file).

## Prerequisites
Ensure you have the following libraries installed before running the notebook:
- numpy
- pandas
- sklearn
- tensorflow
- keras
- torch
  
Install essential libraries manually:

   ```bash
   pip install numpy pandas scikit-learn tensorflow keras torch
   ```

## To use dataset, saved model and features
1. Navigate to the [Kaggle notebook](https://www.kaggle.com/code/harshdeepjadhav/correspondances-final-submission).
2. Use GPU accelerator.
3. Run the code.

## Expected Outputs
- The model should load pre-trained weights or be trained on the provided dataset.
- Predictions should be generated, and give the ARI and NMI score and also display the images belonging to the same cluster for each embedding type.
- Metrics such as ARI, NMI and accuracy scores should be displayed.
